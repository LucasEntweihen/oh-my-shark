# 🌊 Neuro-Task Horizon Update

Este release transforma completamente a experiência do **Oh My Shark**, promovendo o **Gerenciador de Tarefas** à mecânica principal (Landing Page) da aplicação web.

### 🎨 O que há de novo?

- **Novo Design System Escuro**: Implementação 100% fiel ao `DESIGN.md`, abandonando fundos genéricos e adotando cores sofisticadas (`#22242B` para o fundo, `#2A2D36` para as superfícies).
- **Widgets de Produtividade**: O dashboard principal agora inclui **Task List** (estilo checklist animada), **Progress Cards** com trackers visuais e um calendário integrado.
- **Gráficos Complexos e Imersivos**: 
  - **Neural Insights**: Uma área dedicada contendo o `NeuralBust`, uma rede complexa e estátua cibernética reproduzida via vetores e filtros super complexos em SVG.
  - **Crafty Metaverse**: Nova visualização contendo a `GalaxySpiral`, utilizando técnicas avançadas de máscara linear CSS e gradientes para integração profunda ao Dark Mode.
- **Microinterações Neon**: Efeitos de brilho dinâmico (Glitch Cyan, Glow) que reagem a focos e interações, entregando feedback imediato (heurística de Nielsen).
- **Tailwind CSS v4 Nativo**: Transição arquitetural para a mais nova engine do Tailwind de alta velocidade.

### 🛠 Alterações Técnicas
- As rotas da aplicação em `site/` agora integram de forma nativa a nova stack, abandonando a antiga UI genérica de landing page.
- Layout padronizado em Grid/Masonry utilizando `<AppLayout>`, `<Sidebar>` lateral e uma navegação central via `App.tsx`.

*Zero overhead, máxima imersão produtiva. Aproveite a nova era do seu agente focado em execução!*
