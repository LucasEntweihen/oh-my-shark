# OMSK GUI — Interface Gráfica Oficial do Oh My Shark

Aplicativo desktop nativo do Oh My Shark (**OMSK GUI**), construído para execução direta no Windows, Linux e macOS com tema Deep Ocean, visualizador neural da Mente em Teia e integração direta com o motor OMSK.

---

## 🚀 Como Executar o App no seu Computador

### Modo 1: Executável Direto (Dois Cliques)
Dê dois cliques no executável:
- **`apps/omsk-gui/OMSK GUI.exe`**

Ou use o atalho na raiz do repositório:
- **`OMSK GUI.lnk`**

### Modo 2: Via Terminal PowerShell / CMD
```powershell
& ".\apps\omsk-gui\OMSK GUI.exe"
```

### Modo 3: Via Script Bun
```bash
bun run gui:app
```
