# XLR8 Acceleration Command

Accelerate the message process at maximum velocity (`/xlr8`):
- Accelerate the line of reasoning
- Simplify code to the essential minimum
- Optimize the flow of thought for immediate execution
- Disconnect from multi-agent overhead and operate in autonomous basic mode when requested

## Arguments

`$ARGUMENTS`: the task or instruction to execute with accelerated processing.
Pass `--basic` or `basic` as the first token to completely disconnect from all subagents and run as a standalone basic agent.

Execute `$ARGUMENTS` immediately under the XLR8 Maximum Velocity contract.
